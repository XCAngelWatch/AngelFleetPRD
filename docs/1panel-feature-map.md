## AngelFleet 迁移范围

- **首批 M1**　节点注册与在线状态、CPU 和内存及各自采样来源、节点授权与基础审计。GA-01 契约和样例已验证，GA-10 双租户真机验收待执行。[M1 排期与甘特图](go-agent-development-plan.md#m1-排期与甘特图)
- **首批扩展 · FOLLOW**　系统信息、磁盘 I/O、网络和 Top 进程，主机和任务长日志、控制台安全及节点维护。[首批扩展工单](go-agent-development-plan.md#首批功能的后续扩展)
- **后续核心 · CORE**　主机文件与进程、本机/SSH/容器终端、Docker/Compose、已有和远端数据库。先查资源，变更须通过共用写入验证。[后续核心工单](go-agent-development-plan.md#后续核心)
- **后续保障 · OPS**　库和目录备份、面板快照、计划任务、告警及工具箱。恢复须回读数据，告警须验证送达。[后续保障工单](go-agent-development-plan.md#后续保障)
- **条件纳入**　KVM 虚拟机须按版本、许可和节点环境核验，单独安排。[迁移清单](technical-plan.md#137-本轮非-ai-功能迁移清单)

网站、OpenResty 专用流程、应用商店、GPU/AI 和 MCP 由原 1Panel 按需继续管理。上游商业集群、RBAC、SSO 和私有实现须另立范围。各期按选定操作及验收证据开放。[产品范围](product-prd.md#哪些-1panel-功能分批迁移) · [分阶段里程碑](go-agent-development-plan.md#分阶段里程碑)

## 1Panel 上游功能

以下沿用参考导图的 16 个分类。展开功能域可查阅代表性入口和操作。

### 概览

- 系统信息、实时状态、CPU、内存、磁盘 I/O、网络流量和 GPU 状态。
- Top 进程、快捷目录与启动器、已安装及推荐应用、面板重启。

### AI 管理

- 模型检索和下载、下载任务与本地模型、模型账号与连接测试、AI 网关。
- Ollama 等推理引擎、vLLM 监控及硬件探测、GPU 实时与历史指标。
- 数字员工的安装升级、模型主备、技能和插件、消息渠道、角色和会话。
- MCP 服务配置、启停、状态、测试、面板接入、域名与审计。

### 网站管理

- 创建与启停、批量操作、分组、域名和网站模板。
- HTTPS、反向代理、负载均衡、重定向、访问限制及网站日志。
- 证书申请、上传和续期，ACME、DNS 服务商账号及自签 CA。
- PHP、Node.js、Java、Go、Python 和 .NET 运行环境，OpenResty 配置与 WAF 联动。

### 数据库

- MySQL、PostgreSQL、MongoDB 和 Redis 的实例管理，以及远端数据库登记或同步。
- 按引擎管理库、用户权限、远程访问、配置状态、慢日志或持久化。网站或应用关联另有入口。

### 容器

- 容器创建与更新、日志、监控、终端和文件管理。
- 镜像拉取、推送、构建、导入导出及更新检查，镜像仓库管理。
- Compose 与模板、网络与卷、Docker daemon 配置，含镜像加速和代理。

### 应用商店

- 浏览、搜索、筛选应用，安装时配置端口和参数。
- 已安装应用的升级、卸载、日志和更新设定，商店本地或远端同步。

### 备份与快照

- 备份账号和存储目标。本地、S3 兼容存储等目标按实际提供商核对。
- 网站、数据库和目录的备份与恢复、上传恢复及备份记录。
- 面板快照的创建、导入和回滚。

### 告警通知

- 告警规则、触发记录、测试和投递结果。
- 邮件及自定义 Webhook 等渠道。短信及其他渠道随版本、许可和实现变化。

### 主机

- 文件上传下载、压缩解压、编辑预览、权限与所有者、回收站和分享。工具还包括收藏及 AI 搜索入口。
- CPU、内存、I/O 和网络监控，防火墙规则及转发，磁盘分区与挂载。
- 进程、监听端口、SSH 配置和登录记录、Supervisor 服务管理。

### 终端

- 本机、SSH 及容器终端和主机连接管理。
- 常用命令及导入导出，另有 AI 终端设置入口。

### 计划任务

- 定时脚本、网站/数据库/目录备份和日志处理。
- 执行记录、脚本库、分组和导入导出。

### 工具箱

- DNS、主机名、Hosts、时区、NTP、Swap 和系统密码设置。
- Supervisor、ClamAV、Fail2Ban、FTP 和磁盘清理。按节点环境检测可用工具。

### 虚拟机

- KVM 虚拟机创建、编辑、扩容和快照，ISO 镜像导入。
- 虚拟网络、存储池、noVNC 控制台与孤儿资源清理。

### 日志审计

- 操作、登录、系统、主机及网站日志。
- 异步任务日志与清理。

### 面板设置

- 用户、密码、会话超时、主题、语言和水印。
- 安全入口、面板 TLS、多因素认证、Passkey 和 API 密钥。
- 面板升级、菜单和备忘录、任务进度、许可证及版本信息。

### 商业扩展

- 企业用户管理提供角色权限及 AD/LDAP、OIDC、SAML2 接入。
- 多机管理是专业版与企业版的商业能力。虚拟机配额和商店、通知扩展参照版本说明。

## 来源与版本边界

原导图有 16 个分类和 195 个子节点，子节点包含分组说明和跨分类入口。本页将相关操作归并展示。源码与版本边界以 1Panel `dev-v2` 提交 `52790c0` 为核对点，发布版本参见官方 Release。[源码快照](https://github.com/1Panel-dev/1Panel/tree/52790c0dca9579323e2593e55218b5a8e3d68e23) · [v2.5.1 发布说明](https://github.com/1Panel-dev/1Panel/releases/tag/v2.5.1)

- 社区版列有 Ollama 模型管理、MCP 管理、最多 5 个智能体和 10 个 AI 网关用户。专业版与企业版包含 vLLM 模型管理。[AI 路由](https://github.com/1Panel-dev/1Panel/blob/52790c0dca9579323e2593e55218b5a8e3d68e23/frontend/src/routers/modules/ai.ts) · [版本对比](https://1panel.cn/versions.html)
- KVM 仍需系统环境支持。固定提交按目标节点检查虚拟机数量，社区版 1 台、专业版 5 台、企业版不限数量。[虚拟机限额实现](https://github.com/1Panel-dev/1Panel/blob/52790c0dca9579323e2593e55218b5a8e3d68e23/agent/app/api/v2/vm.go#L185-L207)
- 社区版实现了自定义 Webhook。商业多机管理和企业身份集成以各自产品说明为准。[社区告警实现](https://github.com/1Panel-dev/1Panel/blob/52790c0dca9579323e2593e55218b5a8e3d68e23/agent/utils/xpack/helper/alert.go) · [版本对比](https://1panel.cn/versions.html) · [企业用户管理](https://1panel.cn/user-management.html)
