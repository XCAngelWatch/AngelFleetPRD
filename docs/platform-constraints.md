# Cloudflare 平台约束快照

初查于 **2026-11-18**。**2026-11-19** 复核了 Workers 调用预算、D1 批处理以及 Workers Logs 的保留期和存储地域。下表保留当日查阅的服务、套餐、额度和官方出处。项目的部署配置、容量承诺与实测门槛见[技术方案](technical-design.md#部署容量与恢复)。

## 核查日期与平台边界

| 服务 | 核查时的限制或平台行为 | 官方资料 |
|---|---|---|
| Workers Paid | 每个 isolate 内存上限 128 MB。HTTP CPU 默认 30s、可配置到 5min。每次顶层调用最多有 6 路出站连接处于等待响应头阶段，收到响应头后释放该名额。Paid 默认每次 10,000 个子请求，可按 Worker 配置。Worker 未压缩大小 64 MiB。每账户默认 500 个 Worker。startup 约 1s。请求体取决于 Zone 套餐 | [Workers limits](https://developers.cloudflare.com/workers/platform/limits/)、[Service bindings](https://developers.cloudflare.com/workers/runtime-apis/bindings/service-bindings/) |
| D1 Paid | 每库 10 GB、每账户 1 TB。每次 Worker 调用的查询配额为 1,000 次。一次 `db.batch()` 在此配额中计一次，批内各条 SQL 仍逐条执行并受单条限制。Worker invocation 最多 6 个同时 D1 连接（官方限制，不等于单库并发）。单行/字符串/BLOB 2,000,000 bytes。SQL 100 KB。绑定参数 100。函数参数 32。查询最长 30s。结果最多 50 MB。Time Travel 30 天。每库每 10 分钟最多恢复 10 次。每脚本约 5,000 个 bindings。单库单线程、查询逐个处理，拥塞时会排队并可能返回 overloaded | [D1 limits](https://developers.cloudflare.com/d1/platform/limits/) |
| Durable Objects SQLite | 每对象 10 GB。账户 Paid 存储不设固定总量。每账户最多 500 个 DO class。键和值合计 8 MB。SQL 行 8 MB。收到的单条 WebSocket 消息 32 MiB。每请求 6 个同时出站连接。单对象约 1,000 req/s 软上限。CPU 默认 30s、可配置到 5min。DO outbound HTTP body 默认 100 MiB | [Durable Objects limits](https://developers.cloudflare.com/durable-objects/platform/limits/)、[DO spending limits](https://developers.cloudflare.com/durable-objects/platform/spend-management/) |
| Queues | 每账户默认 10,000 个队列。消息 128 KB。最多重试 100 次。consumer batch 最多 100 条。`sendBatch` 最多 100 条或 256 KB。单队列 5,000 msg/s。积压 25 GB。push consumer 并发 250。consumer wall time 15min。保留最长 14 天。pull `visibilityTimeout` 12h。`delaySeconds` 24h。batch 等待上限 60s | [Queues limits](https://developers.cloudflare.com/queues/platform/limits/) |
| Workflows Paid | 单步 CPU 默认 30s、可配置到 5min。单步非流式结果与事件载荷各 1 MiB。单实例状态 1 GB。steps 默认 10,000、最多 25,000。账户并发 50,000。创建速率 300/s/账户、100/s/Workflow。排队实例 2,000,000。完成状态默认保留 7 天、最多 30 天 | [Workflows limits](https://developers.cloudflare.com/workflows/reference/limits/)、[Workflow concurrency](https://developers.cloudflare.com/workflows/build/concurrency-limits/) |
| R2 | 对象最大 5 TiB。单段上传 5 GiB。multipart 最大约 4.995 TiB、10,000 parts。bucket 管理操作 50/s。同一 object key 并发写 1/s。key 1,024 bytes、metadata 8,192 bytes。预签名 URL 是 bearer token，只支持 GET/HEAD/PUT/DELETE 和 S3 API 域名。multipart ETag 不替代整文件摘要 | [R2 limits](https://developers.cloudflare.com/r2/platform/limits/)、[R2 presigned URLs](https://developers.cloudflare.com/r2/api/s3/presigned-urls/)、[R2 conditional operations](https://developers.cloudflare.com/r2/api/s3/conditional-operations/) |
| Cloudflare China Network | 独立 Enterprise 服务，需要 ICP。官方可用性清单列出 Workers、WebSockets、R2、mTLS 等，但未将 D1、Durable Objects、Queues 列入该清单。R2 bucket 不能创建在中国大陆 | [China Network overview](https://developers.cloudflare.com/china-network/)、[Available products](https://developers.cloudflare.com/china-network/reference/available-products/)、[China Network FAQ](https://developers.cloudflare.com/china-network/faq/) |
| WebSockets / Argo | Cloudflare 支持代理 WebSocket。Argo 与 WebSocket 不兼容。长连接需要客户端心跳和重连，负载均衡场景需验证会话亲和性 | [WebSockets](https://developers.cloudflare.com/network/websockets/) |
| Workers / DO spending limits | 达到账户或产品 spending limit 后可能拒绝新的 Worker invocation、DO stub/SQL/storage/alarm 请求。已建立的 WebSocket 不等于新请求仍可用 | [Workers spend](https://developers.cloudflare.com/workers/platform/spend-management/)、[DO spend](https://developers.cloudflare.com/durable-objects/platform/spend-management/) |
| Workers/DO code update | DO 默认可能延迟代码切换，活跃对象在旧代码运行期间与新版本并存。Service Binding 上下游也可能版本错位 | [DO code updates](https://developers.cloudflare.com/durable-objects/deployments/durable-objects-code-updates/)、[Version skew](https://developers.cloudflare.com/workers/versions-and-deployments/version-skew/) |
| Workers Logs / Observability | Paid 保留 7 天。单条超过 256 KB 会被截断，超过每日总量限制会被采样。云端存储地域取决于账户的 Customer Metadata Boundary 配置，未配置时可能在全球核心数据中心保存 | [Workers Logs](https://developers.cloudflare.com/workers/observability/logs/workers-logs/) |
